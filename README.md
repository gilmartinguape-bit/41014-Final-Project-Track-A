# 41014 Sensors and Control in Mechatronic Systems

## Final Project — Track A

### Mobile Robot Visual Waypoint Navigation

This project develops a simulated mobile robot navigation system integrating:

- differential-drive robot modelling
- wheel encoder odometry
- LiDAR sensing
- camera and ArUco sensing
- Extended Kalman Filter state estimation
- LQR feedback control
- MuJoCo simulation

The feedback controller will use the estimated robot state rather than simulator ground truth.
